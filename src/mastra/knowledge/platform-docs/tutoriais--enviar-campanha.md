# Enviando uma Campanha

Envie ou agende uma campanha de maneira simples.

### Como enviar uma campanha

Para começar a configurar um envio, clique no botão **"+ Nova Transmissão"** na aba **"Envios".**

Uma nova janela irá se abrir e você poderá começar a configurar seu envio.

Primeiro, dê um nome a sua campanha. Na opção ***"Dispositivo"**,* selecione com qual dispositivo conectado você deseja realizar os seus envios.

Em seguida, na opção de ***"Campanha"**,* selecione a campanha que deseja enviar. 

Depois na opção ***"Listas",*** selecione para qual lista de contatos deseja enviar sua campanha.

O campo ***"Intervalo"*** representa o **tempo em segundos** que o ZAPN irá esperar para enviar a campanha para o próximo contato.

Logo em seguida, selecione **"Imediato"** para fazer o envio imediatamente ou selecione **"Agendamento"** para agendar o dia e horário que sua campanha será enviada.

Após configurar sua campanha, clique em **"Enviar Agora"** caso tenha selecionado ***"Imediato"*** ou **"Agendar Transmissão"** se tiver selecionado ***"Agendamento".***

### Como acompanhar o envio de uma campanha

Quando uma campanha for iniciada ou agendada, você pode acompanha o status do envio em duas partes.

Na coluna **"Status de Envio",** você irá ver a progressão dos envios a medida que estiverem sendo enviados. 

Caso queira acompanhar a lista de números que estão recebendo os envios mostrando o status ("Enviado", "Erro no Envio"), basta clicar no ícone da lupa. Uma nova janela lateral irá se abrir e você poderá acompanhar os detalhes de cada envio.

### Tag do Envio

As tags irão definir o estado do envio:

* Envio Agendado: Seu envio foi agendado para uma determinada hora e dia.
* Envio Finalizado: Envio foi finalizado com sucesso.
* Envio Cancelado: O envio foi cancelado clicando na tag "Cancelar Envio".
* Cancelar Envio: Se for clicado irá parar o envio que está ocorrendo.

### Perguntas Frequentes

**P: Posso cancelar um envio agendado?**

Sim, basta excluir o envio usando a ícone da lixeira.

**P: Posso alterar a data de um agendamento já criado?**

Sim, basta clicar no ícone do lápis para abrir a janela de edição da campanha, alterar para a data e horário que deseja. Clique em **"Agendar Transmissão".**

**P: É possível parar um envio no meio?**

Sim, basta clicar na tag Cancelar Envio.

**P: Consigo acessar o relatório de envio?**

Sim, basta clicar no ícone de lupa para acessar o relatório de envio.
